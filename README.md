# NW agent LP（公開前プレビュー）

日本・中国・台湾の光学／カメラ業界で、NWが企業同士をつなぐ紹介サービス「NW agent」のランディングページです。
問い合わせ（紹介のご相談）を受け付けることを目的としています。

## 公開前の状態について

- **検索よけ:** `robots.txt` と `<meta name="robots" content="noindex, nofollow">` で検索エンジンに載らないようにしています。
- **未確定の箇所:** `[◯営業日]`（返信の目安）と `[詳しい住所・確定後に記載]`（台湾の住所）は仮置きです。
- **問い合わせフォーム:** 送信の仕組みは未決定です。現在は、ボタンを押すと入力内容が入ったメールの作成画面（宛先：sales2@cnw2018.com）が開きます。

## ファイル

- `index.html` — LP本体（1ファイル完結。スマホ・PC両対応）
- `images/network-map.jpg` — 日本・中国・台湾をつなぐネットワーク図
- `robots.txt` — 検索よけ

## 公開の手順（GitHub Pages）

1. このリポジトリを GitHub にプッシュする
2. リポジトリの Settings → Pages で、Branch を `main` / フォルダを `/ (root)` に設定する
3. 数分後に発行される URL で閲覧できる
